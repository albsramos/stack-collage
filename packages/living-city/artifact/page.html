Living City

The campus illustration, running. Semis back into the factory docks and get loaded at the bay, robotaxis swap passengers, cars charge, the crane swings and humanoid robots work and walk among people. It follows this page's light or dark mode on its own.

Drop it in

import { LivingCity } from 'living-city';

export function Hero() {
  return <LivingCity style={{ borderRadius: 24 }} />;
}

It takes the full width of its container and keeps the scene's 1.86 : 1 shape. Give it a height and it fills that box instead, cropping the edges. It pauses while scrolled out of view.

Dark mode

By default the component matches the page around it, in this order:

  1. A data-theme on any ancestor, or data-bs-theme, data-color-scheme, data-mode or data-mantine-color-scheme, set to "dark" or "light"
  2. A dark or light class on <html> or <body>, as Tailwind and next-themes do
  3. The visitor's system setting

It notices changes as they happen and dissolves into the new look. Pass theme="light" or theme="dark" to fix one.
